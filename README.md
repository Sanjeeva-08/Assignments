INTRODUCTION : 

This repository contains solutions for the assignment programs given. Both programs are implemented using Python 

 
Question1 : 

N-Queens : 

This problem involves placing of N-Queens on N x N Grid such that no Two Queens Attack each other. 

I've used 'Q' to represent a queen and  a  hash symbol '#' to represent an empty space. This program shows all possible solutions and the total number of solutions. 


Question2 : 

Expression Matching:  

This problem involves checking a given string matching a given pattern. 

The plus  '+' symbol represents one or more repetition of the previous character. This program checks whether the complete given string matches the given pattern.
